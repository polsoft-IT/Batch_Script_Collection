## 🚀 Szybki start - działaj w 60 sekund!

### Krok 1: 📥 Pobierz
```powershell
# Sklonuj repozytorium
git clone https://github.com/yourusername/Batch_Script_Collection.git
cd Batch_Script_Collection
```

### Krok 2: ▶️ Uruchom dowolny skrypt
1. **Kliknij prawym przyciskiem** na wybrany skrypt
2. Wybierz **"Uruchom jako administrator"** (zalecane dla skryptów systemowych)
3. Postępuj zgodnie z instrukcjami na ekranie - i gotowe! ✨

### Krok 3: 🎯 Zacznij automatyzować!
Wypróbuj te najpopularniejsze skrypty najpierw:
- 🧹 `Cleaning/Windows and Users Temp Cleaner.bat` - Zwolnij miejsce natychmiast
- 📦 `Install and Update/Python/Python 3.13 Installer.cmd` - Zainstaluj Pythona jednym kliknięciem
- 🚀 `Remove and Uninstall/Debloating Edge.bat` - Usuń niechciane oprogramowanie
- 🎮 `Games/Snake the Batch Game.bat` - Miłej zabawy!
